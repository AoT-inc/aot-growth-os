# ADR-0020 MCP 서버가 없는 서비스는 닫힌 선언 문법의 API 전송으로 같은 커넥터 길에 붙인다

상태: proposed (2026-11-10. 설계: `plans/2026-11-10_aot-integration_design_api-connector.md`, 열린 결정 C1~C8 은 권장안으로 확정). 2026-11-11 개정: 인자 키 `forbidden_chars` 를 더한다(Decision 2 의 `forbidden_chars` 항목, 남는 위험 (2)).

## Context
growth-os 는 조직·역할·권한·승인 규칙을 가진 시스템이고 각 서비스는 MCP(주)와 API(보조)로 연결된다. 에이전트는 연결된 도구를 쓰는 교체 가능한 수행자다. [ADR-0018](0018-mcp-connector.md) 은 MCP 서버를 오너 선언 도구만 게이트웨이로 내주는 커넥터 프로세스를 만들었다. MCP 서버가 없는 서비스(첫 사례: 홈페이지 글을 올리는 gitea)는 HTTP API 만 있다.
위험은 "범용 HTTP 호출기"다. 에이전트가 URL·메서드·헤더·본문을 정하게 되면 정책·승인·원장이 의미를 잃는다. 서비스별 전용 도구를 growth-os 코드에 넣는 것도 방침(서비스 지식은 데이터에만)에 어긋난다.

## Decision
1. **전송 종류 `api` 를 `mcp_sites[]` 에 더한다 (C2).** `transport: { kind: "api", base_url, network }`. 도구(동작)는 같은 배열의 `tools[]` 에 오너가 하나씩 선언한다. 분류 필드(`name, as, description, scope, impact, side_effect, approval, target, unit_cost_usd`)는 MCP 와 **같은 이름·검증·의미**다. 에이전트 도구 이름도 `mcp_<site>_<as>` 그대로다(C1): 정책 행위·역할 설정을 그대로 쓴다. ADR-0018 Decision 1~8 을 그대로 따르고 그 위에 아래를 더한다.
2. **동작 선언은 닫힌 문법이다.** 동작 = `args`(이름→`string|integer|boolean` + `enum, pattern, forbidden_chars, min, max, max_length, required`), `request`(`method` GET|POST|PUT|PATCH|DELETE, `path` 틀, `query`, `body`, 고정 `headers`), 읽기 `returns`, 쓰기 `record`.
   - 값이 들어가는 자리는 `{"$arg":이름}`, `{"$const":값}`, `{"$template":"…{이름|변환}…", "encode":"base64"?}` 셋뿐이다. 이름(키) 자리에는 쓸 수 없고 반복·조건·식이 없다. 본문의 문자열 값은 반드시 이 셋 중 하나이고 알 수 없는 키는 거부한다.
   - 템플릿 변환은 닫혀 있다: `raw`(기본), `json_string`(따옴표 친 JSON/YAML 스칼라), `base64`(UTF-8). 글자 `{`·`}` 는 `{{`·`}}` (C3).
   - 호스트가 정하는 값은 예약 인자 `effect_key`(부작용 원장의 효과 키) 하나이고 쓰기 동작의 `$arg`·템플릿에서만 쓸 수 있다. 에이전트가 주면 거부한다.
   - **`forbidden_chars`(2026-11-11 개정)**: 정규식 없이 "이 글자는 값에 있으면 안 된다" 를 선언한다. 긴 자유 글(블로그 본문 등)에서 `{`·`}`·NUL 같은 몇 글자만 막으려고 패턴을 쓰면 패턴의 길이 상한(2048)에 묶이므로 따로 둔다.
     - 문자열 인자에만 쓴다. 값은 글자 1~16개의 배열이고, 각 항목은 **코드 포인트 하나**인 문자열이어야 하며(짝 없는 서로게이트 불가, 제어 문자·NUL 허용), 서로 달라야 한다. 빈 목록·글자가 아닌 항목·중복·16개 초과·여러 글자 항목·문자열이 아닌 인자(integer·boolean)에 쓰는 것은 선언 단계에서 거부한다. 정규형은 코드 포인트 순으로 정렬한 배열이라 쓴 순서가 달라도 선언 해시는 같다.
     - 의미: 값에 목록의 글자가 **하나라도** 있으면 호출을 거부한다. 비교는 코드 포인트 단위(`for…of`)의 선형 검사이고 글자마다 집합 조회 한 번이라 비용은 값 길이에 비례한다. 시간 제한이 없는 `RegExp` 를 쓰지 않는다. 검사는 호스트와 커넥터가 같은 함수(`checkApiArguments`)로 하고 해시에 들어간다(바꾸면 `closed:drift`).
     - `pattern`·`enum` 과 함께 쓸 수 있고 각각 독립적으로 모두 통과해야 한다. `pattern` 이 있으면 길이 2048 규칙이 그대로 적용된다. 경로 자리 인자의 필수 조건(`pattern` 또는 `enum`)은 `forbidden_chars` 로 채워지지 않는다(글자를 막는 것은 허용 목록이 아니다).
     - `forbidden_chars` 만 쓰고 `pattern` 이 없는 문자열의 `max_length` 상한은 일반 상한(32768)과 같다. 선형 검사라 별도 상한을 두지 않는다. 요청 본문 1 MiB 추정이 실제 한계다.
     - 기존의 "값에 NUL 이 있으면 거부, 짝 없는 서로게이트 거부"(모든 문자열 인자)는 그대로 있다. 본문 인자가 `forbidden_chars` 에 `\u0000` 을 적는 것은 선언에서 의도를 드러내고 해시에 묶기 위한 것이다.
   - 경로 자리의 인자는 `pattern`(또는 `enum`)이 필수, 템플릿·본문 `$arg` 의 인자는 `required` 여야 한다.
   - 쓰기는 `GET` 이 아니고 `approval` 이 필수, 읽기에 `GET` 이 아닌 메서드를 쓰려면 `ack_post_is_read: true`. 쓰기는 `returns` 를 쓸 수 없고 서비스 응답 본문은 에이전트에 가지 않는다. `record` 로 고른 필드만 원장 응답 기록에 남는다.
   - `idempotency`(서비스 쪽 멱등 키 인자)는 1단계에서 지원하지 않는다. `effect_key` 를 본문(커밋 메시지 등)에 넣어 사람이 서비스에서 반영 여부를 찾게 한다.
3. **요청은 순수 함수가 조립한다.** 같은 선언·인자는 같은 요청 바이트를 낸다. 경로 인자는 `/`·`\`·제어문자를 담을 수 없고 한 구간으로 퍼센트 인코딩하며 `.`/`..` 구간·`%2f`·`%5c` 가 나오면 보내지 않는다. 쿼리는 선언된 키만, 값은 인코딩한다. 본문은 JSON 직렬화이므로 값이 구조를 바꿀 수 없다. 요청 본문은 1 MiB 이하이고 선언 검증이 최대 크기를 추정해 넘으면 거부한다.
4. **전송은 커넥터 프로세스 안에서 한다.** 새 전송이 `list`(선언에서 합성한 도구 목록)와 `call`(HTTP 실행)에 답한다. 데몬·정책·승인·원장·속도 제한·상태 감시는 MCP 와 같은 코드다(`main.ts` 의 전송 분기 한 곳만 더한다). 규칙:
   - 요청 URL 은 `base_url` 출처 + 조립한 경로뿐이다. **리다이렉트는 따르지 않는다**(3xx 는 실패, 본문을 읽지 않는다).
   - 주소 해석 결과 **모두**가 규칙 안일 때만 연결하고, 연결은 검사한 바로 그 주소로 고정한다(DNS 재해석 방지). `network: "public"`(기본)은 공인 주소만, `"tailnet"` 은 공인 + 100.64.0.0/10, `"loopback"` 은 `base_url` 호스트가 루프백일 때만 루프백 주소(로컬 개발·시험용, http 허용). 링크로컬·RFC1918 은 어느 경우에도 거부한다. `fetch_url` 과 달리 오너가 선언한 호스트에 한해 tailnet 을 허용한다.
   - 응답은 `application/json`·`+json` 만 읽고 `content-encoding` 응답은 읽지 않는다. 256 KiB 에서 자르면 읽기는 `tool_error`(truncated)다. `returns` 에 적힌 경로의 필드만 돌려주고(`*` 는 배열 원소) 경로가 없으면 `tool_error`. 모든 결과는 `external_untrusted`.
   - 시간 제한 `timeout_ms`, 분당 상한, 비밀 가림(응답·오류에 토큰이 되돌아오면 `[redacted]`)은 MCP 와 같다. 조립한 URL·헤더·본문은 로그·기록에 남기지 않는다.
5. **인증은 `none|bearer|header` 를 그대로 쓴다.** 비밀은 환경 변수 *이름*으로만 선언하고 커넥터 프로세스 환경으로만 간다. 서비스가 `Authorization: token <값>` 을 요구하면 `header` 종류에 `Authorization` 과 값 `token xxx` 인 환경 변수를 쓴다. `oauth_delegated` 는 api 사이트에서 지원하지 않는다(후속, 서비스의 동적 등록 필요).
6. **선언 고정(`pin`).** 도구 선언에 `input_schema_sha256` 대신 `pin` 을 쓴다. `pin` = 합성 입력 스키마(인자 틀 + 선언 해시)의 해시이고 선언 해시는 `base_url`, `network`, 인증 종류와 헤더 이름, 동작 이름·분류·승인·대상, `args`, `request`, `returns`, `record` 의 정규 JSON sha256 이다(설명·`as` 제외). 선언이 `pin` 과 다르면 그 도구는 `closed:drift` 로 닫힌다 — 시작, 주기, **쓰기 전송 직전마다** 확인하는 기존 경로다. 쓰기 초안에는 `pin` 이 같이 저장되고 전송 때 현재 `pin` 과 다르면 보내지 않고 `failed`: 승인 뒤 선언이 바뀐 채 전송되지 않는다. 서비스 쪽 변화는 이 고정이 못 잡는다(응답 모양 검사가 읽기에서 잡는다). `npm run mcp-pin`(별칭 `api-pin`)이 합성 스키마 해시를 출력한다.
7. **결과 판정(쓰기).** 보내기 전 실패(닫힘·인자·해시·속도·주소·DNS·연결 실패)와 4xx·3xx 는 `failed`, 2xx 는 `confirmed`, 5xx·요청을 보낸 뒤의 시간 초과·연결 끊김은 `unknown`(자동 재전송 없음, 사람이 `resolve-effect`). 동작별 판정 변경은 하지 않는다(C6).

## Consequences
- 서비스 추가는 선언 데이터 수십 줄이다. 문법에 없는 API(멀티파트, 스트리밍, 쿠키 세션, 페이지 순회, 응답을 보고 다음 요청을 정하는 흐름)는 억지로 붙이지 않고 (나) 얇은 MCP 서버로 붙인다.
- 문법이 커질수록 범용 호출기에 가까워진다. 새 값 자리·변환·메서드는 이 ADR 의 개정으로만 더한다. 시험이 선언 밖 요청·주입·리다이렉트·사설망을 고정한다.
- 남는 위험: (1) 토큰 권한이 곧 울타리다 — 서비스 쪽에 최소 권한 전용 계정이 필수다. (2) 선언된 `pattern` 은 데몬 프로세스에서 에이전트 값으로 실행된다: 값 전체 일치로 검사하고, 패턴이 있는 문자열은 길이 2048 이하이며 중첩 반복·선택 모양과 역참조는 선언 단계에서 거부한다(휴리스틱이므로 모든 비싼 패턴을 막지는 못한다). 긴 자유 글에서 몇 글자만 막을 때는 패턴 대신 `forbidden_chars`(선형, 일반 길이 상한만 적용)를 쓴다. `network: "loopback"` 은 개발·시험 전용이고 운영에서 쓰지 않는다. tailnet 의 IPv6 대역은 지원하지 않는다. (3) `pin` 은 서비스 쪽 변화를 못 잡는다. (4) 4xx 가 부분 반영인 서비스는 `unknown` 이 아니라 `failed` 로 기록된다. (5) 연결 고정은 커넥터 안 구현이라 별도 OS 격리는 없다(ADR-0018 과 같음). (6) 응답 본문 속 지시문은 `external_untrusted` 표시와 필드 허용 목록으로만 다룬다.
- 새 런타임 의존을 더하지 않는다(`node:http(s)`, `node:dns`). 커넥터 폴더의 격리 규칙(내장 모듈과 같은 폴더만 import)을 지킨다. 그래서 `ip-address.ts` 규칙을 커넥터 폴더에 복사해 두었다(두 사본이 어긋나지 않게 시험이 대조한다).
- 후속: OpenAPI 에서 선언 초안만 만드는 명령, 이미지 업로드, 읽기 전용 토큰 분리, `oauth_delegated`.
